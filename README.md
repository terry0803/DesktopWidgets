# Desktop Widgets

用 Rust 寫的低耗電桌面小工具，放在桌面最底層，有翻頁時鐘、日曆、天氣、倒數、時間進度和待辦。

## 使用

`build.ps1` 會把程式裝到 `%LOCALAPPDATA%\Programs\DesktopWidgets`，設定和待辦也存在那裡。這個資料夾在 C 槽，所以原始碼所在的磁碟拔掉了，小工具照樣能開。從開始功能表開「桌面小工具」就行：程式第一次啟動時會自己建立這個捷徑。

- 工作列右下角的通知區有它的圖示，左鍵或右鍵都會開出整體的選單：整體大小、顯示卡片、鎖定、重設、開機時啟動、結束。卡片被視窗蓋住時也找得到它。Windows 11 會先把新圖示收在 ^ 裡，可以拖到工作列上，或在「設定 > 個人化 > 工作列 > 其他系統匣圖示」打開
- 開機自動啟動可以在「設定 > 應用程式 > 啟動」裡開關，名稱是「桌面小工具」。第一次啟動時會加進那份清單，預設是關的；選單裡的「開機時啟動」和設定裡的開關是同一個

- 拖曳卡片可以移動，位置會記住。靠近其他卡片或螢幕邊緣時會顯示預覽框，放開後自動對齊，而且一定留在螢幕內；按住 Ctrl 拖曳就不對齊
- 右鍵選小、中、大調整大小。卡片會往有空位的方向長，真的沒位子才把其他卡片推開。大尺寸顯示更多內容，不只是放大
- 右鍵卡片可以顯示或隱藏卡片、鎖定位置、重設位置和大小、設定開機啟動、結束程式。鎖定時不能移動、改大小、改整體大小或重設
- 右鍵的「整體大小」可以把所有卡片一起縮放成 75%、85% 或 100%，預設 85%。Apple 的尺寸來自 iPhone，放在筆電上偏大
- 待辦：按右上角的 + 在卡片上直接打字，Enter 新增，Esc 取消，點別處保存，注音還沒確認的字也會留下。點一下項目勾選，右鍵項目可以刪除。未完成的排前面。項目比卡片多時用滾輪，或點最後一列的「還有 N 項」往下看
- 倒數：右鍵選「編輯倒數」，名稱和日期都在卡片上直接改。右鍵選「改成正數（從某一天算起）」就改成從那天算起的第幾天，那天本身算第 1 天，例如「在一起 365 天」，接著直接改名稱和起始日；再選一次改回倒數。名稱按 Enter 接著改日期，點別處就只存名稱；在日期按 Esc 兩個都不改。日期可以寫 2027-1-1、2027/1/1、2027.1.1 或 2027年1月1日。打錯時按 Enter 會留在輸入框；直接點別處就只存名稱，卡片會提示日期沒改
- 天氣：自動依網路位置定位。右鍵選「編輯地區」可以輸入地名，打目前顯示的地名再按 Enter 就是固定在這裡，選「使用目前位置」改回自動。沒改字就點別處，什麼都不會變。找不到的地名會顯示在卡片上，沒有網路時之後會再試。「今天」和高低溫看的是當地的日期
- 跟著 Windows 的深色或淺色模式

設定存在程式旁邊的 `widgets.ini`，待辦存在 `todo.txt`，都是純文字。

- 程式開著時用記事本改 `todo.txt` 也可以。下一次點待辦卡片、按右鍵或滾滾輪時會先讀回來，這一下只更新畫面，不會勾到或刪到別的項目，只有 + 照常。改 `widgets.ini` 要先結束程式
- `todo.txt` 不見時卡片上的清單還在，下次存檔或結束程式時會寫回去。要清空清單請在卡片上刪
- 檔案不是 UTF-8、有看不懂的行，或存檔前發現被別的程式改過，原檔會先留一份 `.bak`，最多 9 份，滿了蓋掉最舊的
- 啟動時檔案打不開就不會覆蓋它，之後每分鐘再讀一次。讀到後待辦接回去，這段時間新增的排在後面；設定則以檔案為準。`widgets.ini` 打不開時也不會連網，因為不知道地區是不是手動輸入的
- 存檔失敗時每分鐘重試，待辦卡片顯示「未儲存」，右鍵選單最上面也會提示。結束程式、登出或關機時還是存不進去，內容會放在 `todo.unsaved.txt` 和 `widgets.unsaved.ini`，原檔不動

## 建置

需要 Rust 的 `stable-x86_64-pc-windows-gnu` 工具鏈。不用裝 Visual Studio。

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
powershell -ExecutionPolicy Bypass -File build.ps1 -Test
```

`windows` crate 固定在 0.59，`windows-result` 和 `windows-strings` 固定在 0.3.0。之後的版本編譯時要用 `dlltool` 加組譯器，這個工具鏈沒有附組譯器。

程式的圖示和名稱在 `resources\`：`make.py`（Python 加 Pillow）畫出圖示，寫成 `app.o`，`build.rs` 把它連進程式。改了圖示或名稱就重跑 `make.py`。這個工具鏈沒有 windres，所以 `make.py` 自己寫出連結器認得的格式。

`desktop-widgets.exe --dump <資料夾>` 會把每張卡片輸出成 BMP，不用開桌面也能檢查畫面。

## 設計

參考 Apple 的 Human Interface Guidelines 和 Mac 桌面小工具的行為：

- 尺寸：小 158×158、中 338×158、大 338×338，間距 22，兩張小卡加間距剛好等於一張中卡。大尺寸的高度比 Apple 的 354 小，這樣才能對齊兩列
- 連續曲線圓角，外層 12，內層圓角是外層減去留白。比 Apple 小，配合 Windows 視窗和筆電的圓角
- 大數字細、小字中等字重而且明亮，質感來自這個對比。全部變細反而顯得淡
- 中文用 Noto Sans TC，比微軟正黑體接近蘋方，沒安裝時由 Windows 替代。數字用 Segoe UI Variable，大字 Display、小字 Text，對應 SF Display 和 SF Text。蘋方和 SF 的授權不能用在 Windows
- 關掉 DirectWrite 預設的對比增強，筆畫才不會偏厚
- 背景是模糊過的桌布，只取明暗：啟動和換桌布時算一次，平常只畫一張縮小的圖，不用 GPU 即時模糊。桌布不是「填滿」時改用純色，因為算出來的位置會對不上
- 永遠單色，對應 Mac「讓桌面上的小工具變暗」的「總是」。不切換，所以開關 App 時畫面不會變。桌布再鮮豔，卡片也不會帶顏色。唯一的例外是用滑鼠在輸入框裡選字，那是 Windows 的系統選取色
- 擺放是自由的，沒有全螢幕格線，只有靠近鄰卡或邊緣才吸附。卡片不會互相重疊，也不會蓋到桌面圖示，圖示本身不會被移動。啟動時不看圖示，因為這時 Explorer 可能還沒排好
- 解析度或顯示比例改變時，卡片會暫時移到放得下的地方，但不存檔，換回來就回到原位

## 天氣與網路

- 網路 IP 會送到 [ipwho.is](https://ipwho.is) 取得大略位置，每次啟動一次，之後約 6 小時一次，查不到時隨下一次天氣更新再試。手動輸入地區時不會送
- 座標會送到 [Open-Meteo](https://open-meteo.com) 取得天氣，約 30 分鐘一次，不需要帳號
- 手動輸入的地名會送到 Open-Meteo 的地名查詢
- 螢幕關閉、鎖定，或天氣卡片隱藏時不連網。失敗時保留舊資料，2 分鐘起逐步拉長重試間隔，最長 30 分鐘，超過 3 小時沒更新會顯示上次更新時間，超過一天顯示幾天前

## 怎麼省電

- 沒有繪圖迴圈。只有一個對齊整分鐘的計時器，每次觸發時比對內容，有變才重畫
- 螢幕關閉或電腦鎖定時完全不排計時器
- 卡片是分層視窗，畫面由 Windows 保存，所有卡片共用一塊暫存點陣圖
- 翻頁動畫只在換分鐘時播放，用電池時，或時鐘被別的視窗整個蓋住時不播
- 程式向 Windows 宣告效率模式（EcoQoS）

## 實測

插電時量測，2026-11-07 的版本。拖曳卡片時用量會短暫升高，不算在內：

| 項目 | 數值 |
|---|---|
| CPU，沒有操作、時鐘被視窗蓋住 | 約 0.5 到 0.8 M cycles/s |
| CPU，時鐘露出、每分鐘翻頁一次 | 約 4 M cycles/s：一次翻頁約 200 M cycles，8 到 9 格畫面 |
| 執行緒切換，沒有操作時 | 每分鐘約 20 到 40 次 |
| 工作集記憶體 | 約 40 MB，使用中約 50 MB |
| 私有記憶體 | 約 18 到 21 MB |
| 程式大小 | 611 KB，其中約 100 KB 是圖示 |

Direct2D 的軟體繪圖會載入 `D3D10Warp`，它會開背景執行緒，切換次數大多來自這裡。

`desktop-widgets.exe --soak <紀錄檔> <輪數>` 會反覆繪製所有卡片，並對本機關閉的連接埠發失敗請求，再記錄記憶體和控制代碼。3000 輪（48016 次繪製，61 次失敗請求）裡 GDI 和 USER 物件固定不變，私有記憶體在 21 到 27 MB 之間上下擺動，沒有往上爬。控制代碼從約 270 個升到約 370 個後持平，增加的是 Windows 網路元件（WinHTTP）自己保留的：單獨連發 800 次失敗請求，數量停在約 240 個。

## 還沒實測

- 用電池時關閉翻頁動畫，以及時鐘被蓋住時不播
- 翻頁動畫的實際播放
- 拖曳中被 Alt+Tab 打斷
- 按 Win+D 後使用右鍵選單，視窗不會跑回來，以及這時按 Alt+F4（程式不會結束，但要先點一下桌面，桌面才收得到按鍵）
- 淺色模式
- 沒有網路時的重試，以及超過 3 小時顯示上次更新時間
- 更換桌布後重新載入，以及「填滿」以外的桌布顯示方式
- 螢幕關閉和鎖定時暫停
- 真的登出或關機。輸入框收尾只用模擬的系統詢問測過
- Explorer 重新啟動後重建卡片
- 解析度和顯示比例改變，多螢幕和不同 DPI。卡片會留在各自的螢幕內，但背景的桌布只算主螢幕
- 其他輸入法。注音有實測，別的輸入法走同一條路但沒試過
